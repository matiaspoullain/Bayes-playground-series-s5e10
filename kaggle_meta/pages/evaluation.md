Submissions are evaluated using the [Root Mean Squared Error](https://en.wikipedia.org/wiki/Root_mean_square_deviation) between the predicted and the observed target.

## Submission File
For each `id` in the test set, you must predict a `accident_risk` of between 0 and 1. The file should contain a header and have the following format:

    id,accident_risk
    517754,0.352
    517755,0.992
    517756,0.021
    etc.
